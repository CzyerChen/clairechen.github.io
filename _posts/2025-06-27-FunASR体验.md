要在不联网的服务器上使用 Docker 部署 FunASR 离线语音识别系统，需提前准备模型文件并合理分配资源。以下是详细步骤和资源要求：

---

### ⚙️ 一、资源需求（最低配置）
1. **CPU**  
   - **核心数**：4 核（推荐 8 核以支持更高并发）。
2. **内存**  
   - **基础模型**：≥ 4 GB（处理短音频）  
   - **大型模型（如 Paraformer-large）**：≥ 8 GB（处理长音频或高并发）。
3. **存储空间**  
   - **Docker 镜像**：约 2 GB  
   - **模型文件**：约 2–3 GB（单模型）  
   - **预留空间**：≥ 10 GB（建议为多模型和热词文件预留）。

---

### 🔧 二、操作步骤（离线部署）
#### ✅ 阶段一：联网环境准备
1. **下载 Docker 镜像**  
   ```bash
   docker pull registry.cn-hangzhou.aliyuncs.com/funasr_repo/funasr:funasr-runtime-sdk-cpu-0.4.5
   ```
   - 镜像标签需选择支持离线运行的版本（如 `funasr-runtime-sdk-cpu-*`）。

2. **下载模型文件**  
   - 从 ModelScope 下载所需模型，保存至本地目录（示例路径：`/home/funasr/models`）：  
     ```bash
     # 示例模型（VAD+ASR+标点）
     wget https://modelscope.cn/api/v1/models/damo/speech_fsmn_vad_zh-cn-16k-common-onnx/repo?Revision=master -O vad.tar.gz
     wget https://modelscope.cn/api/v1/models/damo/speech_paraformer-large_asr_nat-zh-cn-16k-common-vocab8404-online/repo?Revision=master -O asr.tar.gz
     ```
   - 解压模型至目录（如 `vad/`, `asr/`）。

3. **导出镜像与模型**  
   - 将镜像保存为压缩文件：  
     ```bash
     docker save -o funasr.tar funasr:funasr-runtime-sdk-cpu-0.4.5
     ```
   - 打包模型目录：  
     ```bash
     tar -czvf funasr-models.tar.gz /home/funasr/models
     ```

---

#### 🖥️ 阶段二：离线服务器部署
1. **导入 Docker 镜像**  
   ```bash
   docker load -i funasr.tar
   ```

2. **加载模型文件**  
   ```bash
   mkdir -p /home/funasr/models
   tar -xzvf funasr-models.tar.gz -C /home/funasr/models
   ```

3. **启动 Docker 容器**  
   ```bash
   docker run -p 10095:10095 -itd \
     --name funasr-offline \
     -v /home/funasr/models:/workspace/models \
     funasr:funasr-runtime-sdk-cpu-0.4.5
   ```
   - `-v` 参数将本地模型目录映射到容器内。

4. **启动离线识别服务**  
   ```bash
   docker exec -it funasr-offline bash
   cd /workspace/FunASR/runtime
   nohup bash run_server.sh \
     --model-dir /workspace/models/asr \  # 指向解压后的ASR模型
     --vad-dir /workspace/models/vad \    # 指向VAD模型
     --punc-dir /workspace/models/punc \  # 标点模型
     --certfile 0 \                       # 关闭SSL
     --hotword /workspace/models/hotwords.txt > log.txt 2>&1 &
   ```
   - 参数说明：  
     - `--certfile 0`：禁用 HTTPS  
     - `--hotword`：加载热词文件（每行格式：`热词 权重`，如 `阿里巴巴 20`）。

---

### 🧪 三、验证服务
1. **本地测试客户端**  
   - 使用官方测试工具（需提前下载）：  
     ```python
     python funasr_wss_client.py --host 127.0.0.1 --port 10095 --mode offline --audio_in input.wav
     ```
   - 若返回识别文本，则服务正常。

2. **查看日志**  
   ```bash
   tail -f /workspace/FunASR/runtime/log.txt  # 监控服务状态
   ```

---

### ⚠️ 四、注意事项
1. **模型兼容性**  
   - 确保下载的模型与镜像版本匹配（如 ONNX 格式）。
2. **热词配置**  
   - 热词文件需提前生成（权重范围 1~100），建议不超过 1000 个词。
3. **资源调优**  
   - 调整线程参数（如 `--model-thread-num`）以匹配 CPU 核心数，提升并发能力。
4. **离线更新模型**  
   - 通过 U 盘等介质将新模型传输至服务器，替换旧模型后重启容器。

---

### 💎 总结
- **资源底线**：4 核 CPU + 4GB 内存 + 10GB 存储（小型应用）。  
- **核心步骤**：联网环境预下载 → 离线服务器加载 → 启动容器与服务 → 验证连通性。  
- **关键配置**：模型路径映射、关闭 SSL、热词加载。

> 部署完成后，可通过 `ws://服务器IP:10095` 调用服务（如 C#/Python 客户端）。完整脚本参考 [FunASR GitHub](https://github.com/alibaba-damo-academy/FunASR)。
