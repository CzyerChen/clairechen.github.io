## RustFS部署

RustFS是一个基于Rust语言构建的高性能分布式对象存储系统，兼容S3协议，可作为MinIO的优秀替代方案。以下是几种常见的部署方式：

### 一键安装脚本
这是最简单的部署方式，适合快速体验RustFS：
```bash
curl -O https://rustfs.com/install_rustfs.sh && bash install_rustfs.sh
```
执行完毕后，RustFS会自动安装并启动服务。

### Docker部署
使用Docker可以快速部署RustFS，无需担心环境依赖问题：
```bash
docker run -d -p 9000:9000 -p 9001:9001 -v /data:/data rustfs/rustfs
```
- `-d`：后台运行容器
- `-p 9000:9000`：映射S3 API端口
- `-p 9001:9001`：映射Web控制台端口
- `-v /data:/data`：将本地/data目录挂载到容器中存储数据

### 源码编译部署
如果需要自定义构建或贡献代码，可以从源码编译：
```bash
# 克隆仓库
git clone https://github.com/rustfs/rustfs.git
cd rustfs

# 编译发布版本
cargo build --release

# 启动服务
./target/release/rustfs /data --address 0.0.0.0:9000
```

### 访问控制台
部署完成后，打开浏览器访问 http://localhost:9001 即可进入RustFS控制台。默认用户名和密码均为 `rustfsadmin`。首次登录后建议修改密码以确保安全。

## SpringBoot访问RustFS，增删查

由于RustFS兼容S3协议，我们可以使用Spring Cloud AWS或AWS SDK for Java来实现SpringBoot与RustFS的集成。

### 1. 添加依赖
在`pom.xml`中添加以下依赖：
```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
</dependency>
<dependency>
    <groupId>io.awspring.cloud</groupId>
    <artifactId>spring-cloud-aws-starter-s3</artifactId>
    <version>3.0.0</version>
</dependency>
```

### 2. 配置RustFS连接
在`application.properties`中添加配置：
```properties
# 配置S3端点（RustFS服务地址）
spring.cloud.aws.s3.endpoint=http://localhost:9000
# 禁用AWS区域配置
spring.cloud.aws.region.static=us-east-1
spring.cloud.aws.region.auto=false
# 访问密钥和密钥ID（RustFS默认）
spring.cloud.aws.credentials.access-key=rustfsadmin
spring.cloud.aws.credentials.secret-key=rustfsadmin
```

### 3. 实现文件上传功能
```java
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;
import org.springframework.web.multipart.MultipartFile;
import software.amazon.awssdk.core.sync.RequestBody;
import software.amazon.awssdk.services.s3.S3Client;
import software.amazon.awssdk.services.s3.model.PutObjectRequest;

import java.io.IOException;

@Service
public class FileService {

    @Autowired
    private S3Client s3Client;

    // 上传文件
    public String uploadFile(String bucketName, String key, MultipartFile file) throws IOException {
        // 确保存储桶存在
        if (!s3Client.listBuckets().buckets().stream()
                .anyMatch(bucket -> bucket.name().equals(bucketName))) {
            s3Client.createBucket(b -> b.bucket(bucketName));
        }

        // 上传文件
        s3Client.putObject(
                PutObjectRequest.builder()
                        .bucket(bucketName)
                        .key(key)
                        .build(),
                RequestBody.fromInputStream(file.getInputStream(), file.getSize())
        );

        return "Successfully uploaded: " + key;
    }
}
```

### 4. 实现文件下载功能
```java
// 下载文件
public byte[] downloadFile(String bucketName, String key) {
    return s3Client.getObjectAsBytes(b -> b.bucket(bucketName).key(key)).asByteArray();
}
```

### 5. 实现文件删除功能
```java
// 删除文件
public String deleteFile(String bucketName, String key) {
    s3Client.deleteObject(b -> b.bucket(bucketName).key(key));
    return "File deleted successfully: " + key;
}
```

### 6. 实现文件列表查询功能
```java
// 查询文件列表
public List<String> listFiles(String bucketName) {
    return s3Client.listObjects(b -> b.bucket(bucketName))
            .contents().stream()
            .map(s3Object -> s3Object.key())
            .collect(Collectors.toList());
}
```

### 7. 创建控制器
```java
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.http.HttpHeaders;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;
import org.springframework.web.multipart.MultipartFile;

import java.io.IOException;
import java.util.List;

@RestController
@RequestMapping("/api/files")
public class FileController {

    @Autowired
    private FileService fileService;

    @PostMapping("/upload")
    public String uploadFile(@RequestParam("bucketName") String bucketName,
                             @RequestParam("key") String key,
                             @RequestParam("file") MultipartFile file) throws IOException {
        return fileService.uploadFile(bucketName, key, file);
    }

    @GetMapping("/download/{bucketName}/{key}")
    public ResponseEntity<byte[]> downloadFile(@PathVariable String bucketName,
                                             @PathVariable String key) {
        byte[] data = fileService.downloadFile(bucketName, key);
        HttpHeaders headers = new HttpHeaders();
        headers.add(HttpHeaders.CONTENT_DISPOSITION, "attachment; filename=\"" + key + "\"");
        return new ResponseEntity<>(data, headers, HttpStatus.OK);
    }

    @DeleteMapping("/{bucketName}/{key}")
    public String deleteFile(@PathVariable String bucketName,
                             @PathVariable String key) {
        return fileService.deleteFile(bucketName, key);
    }

    @GetMapping("/list/{bucketName}")
    public List<String> listFiles(@PathVariable String bucketName) {
        return fileService.listFiles(bucketName);
    }
}
```

## 访问报错汇总

在使用SpringBoot访问RustFS过程中，可能会遇到以下常见错误：

### 1. 连接超时错误
**错误信息**：`java.net.SocketTimeoutException: Connect timed out`
**可能原因**：RustFS服务未启动、网络不通或端口未正确映射。
**解决方案**：
- 检查RustFS服务是否正在运行
- 验证网络连接是否正常
- 确认端口映射是否正确（默认9000端口）

### 2. 认证失败错误
**错误信息**：`software.amazon.awssdk.services.s3.model.S3Exception: The request signature we calculated does not match the signature you provided. Check your key and signing method.`
**可能原因**：访问密钥或密钥ID不正确。
**解决方案**：
- 确认`application.properties`中的`access-key`和`secret-key`是否正确
- 检查RustFS控制台中的用户凭证

### 3. 存储桶不存在错误
**错误信息**：`software.amazon.awssdk.services.s3.model.NoSuchBucketException: The specified bucket does not exist`
**可能原因**：尝试访问的存储桶不存在。
**解决方案**：
- 确保在RustFS控制台或通过API创建了相应的存储桶
- 检查存储桶名称是否拼写正确

### 4. 文件不存在错误
**错误信息**：`software.amazon.awssdk.services.s3.model.NoSuchKeyException: The specified key does not exist`
**可能原因**：尝试访问的文件不存在于指定的存储桶中。
**解决方案**：
- 确认文件密钥（key）是否正确
- 检查文件是否已成功上传到存储桶

### 5. 权限不足错误
**错误信息**：`software.amazon.awssdk.services.s3.model.AccessDeniedException: Access Denied`
**可能原因**：当前用户没有足够的权限执行操作。
**解决方案**：
- 检查RustFS用户权限设置
- 确保使用的凭证具有相应的操作权限
